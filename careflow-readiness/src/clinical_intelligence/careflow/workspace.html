Requests

Start from a clinical note or dialogue

Luna extracts a source-linked clinical draft. The checklist checks the separate materials you supply. A diagnosis or treatment plan does not create an order, PA form or completed course.

An explicit reason associates matching clinical proposals with this request. The program separately checks their original source, patient, polarity and time. A matching word alone is not proof.

Associate a treatment or test with this request

Select the evidence this request calls for and name its clinical concept as it appears in the note. This associates extracted evidence; it does not declare a completed course or create a received document.

Accepted files contain original CareFlow Source records: one record, a source array, or an object with sources. PDF/image parsing is not available. Uploaded request, patient and service fields are preserved and checked; they are never filled from the clinical text.
